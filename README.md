# 电影导演实验室 · 内置参考库

Google Flow 自定义工具「电影导演实验室」的内置电影参考库。工具打开时通过 jsDelivr 自动加载 `library.json`。

## 内容

| 来源 | 影片 | 镜头 |
|---|---|---|
| 历代奥斯卡最佳摄影（2026–2003） | 24 部 | 67 个 |
| 诺兰导演镜头集锦（Memento → Tenet） | 10 部 | 82 个 |

每个镜头包含：关键帧、片名、构图 / 光影 / 色彩 / 运镜 / 情绪描述、5 色色卡、关键词（含年份与摄影师）。

## 文件

- `library.json`：工具读取的数据（格式 `cinematic-director-lab/library` v1，缩略图内嵌为 data URL）
- `images/`：各镜头关键帧原图
